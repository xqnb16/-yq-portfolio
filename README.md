## 发布

这是一套无需构建的静态网站。将本目录内容上传到 GitHub 仓库，在 **Settings → Pages** 选择 **Deploy from a branch → main → /(root)** 并保存即可。

详细操作见 [GitHub Pages 上传说明](GitHub-Pages上传说明.md)。
